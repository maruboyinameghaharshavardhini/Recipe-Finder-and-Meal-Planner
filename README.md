# Recipe-Finder-and-Meal-Planner

📌 Project Description

RecipeNest is a user-friendly frontend web application developed using HTML, CSS, and JavaScript. It helps users discover recipes, search for dishes by name or ingredients, save favorite recipes, plan weekly meals, and generate shopping lists for convenient meal preparation.

🎯 Objectives

- Make recipe discovery simple and convenient.
- Search recipes by name or ingredients.
- Filter recipes by category.
- Save and manage favorite recipes.
- Organize meals for the week.
- Generate shopping lists from planned meals.
- Provide a simple and interactive user interface.

✨ Features

- Recipe Search: Find recipes using keywords.
- Category Filters: Explore recipes by food category.
- Favorite Recipes: Save preferred dishes for quick access.
- Recipe Details: View ingredients and preparation instructions.
- Weekly Meal Planner: Organize meals for different days.
- Shopping List: Collect ingredients needed for planned meals.
- Local Storage: Preserve supported data in the browser.
- Responsive Design: Designed to adapt to different screen sizes.

🛠️ Technologies Used

- HTML5 – Structures the webpage.
- CSS3 – Styles the interface and layout.
- JavaScript – Implements interactive features and application logic.
- Browser Local Storage – Saves supported user selections.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that "index.html", "style.css", and "script.js" are in the correct locations.
4. Open "index.html" in a web browser, or use the Live Server extension in Visual Studio Code.
5. Explore recipes, save favorites, plan weekly meals, and create shopping lists.

💡 How It Works

RecipeNest uses a predefined collection of recipes stored in JavaScript. Users can search and filter this collection, view recipe details, and select dishes for their weekly meal plan. The shopping-list feature uses ingredient information from planned recipes to help organize grocery requirements. Browser local storage retains supported selections between visits in the same browser profile.
